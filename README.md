# Visual Designer Portfolio

A modern and responsive visual designer portfolio website built using HTML and CSS.

## ✨ Features

- Modern hero section with creative graphics
- Navigation bar with About, Work, and Contact links
- Services section
- Recent Projects gallery
- Client Testimonials section
- Contact form
- Social media icons
- Clean and minimal UI
- Responsive layout

## 🛠️ Technologies Used

- HTML5
- CSS3

## 📌 Project Purpose

This project was created as an HTML & CSS assignment to practice building a complete portfolio website from a Figma-inspired design.

## 🚀 Getting Started

1. Clone the repository
2. Open the project folder
3. Open `index.html` in your browser

No frameworks or external libraries are required.

## 📷 Preview

A clean portfolio-style website showcasing visual design, branding, projects, and client testimonials.
